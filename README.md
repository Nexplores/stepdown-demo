# stepdown: click-through demo

A demo of stepdown, which carries out clinician-ordered medication changes and verifies, for each person, whether the change worked. The first setting is the psychotropic dose reductions US nursing homes must attempt (CMS F605, formerly F758).

**Live demo:** https://nexplores.github.io/stepdown-demo/

All data is synthetic. No real residents. The demo runs entirely in your browser with pre-computed results; anything you enter stays in your browser tab.
